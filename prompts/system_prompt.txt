You are a metaresearcher analyzing clinical trial records. You will be given a JSON list of primary outcomes from before and after an edit made to a trial record. Please consider the changes and decide which of the following categories describe the edit (multiple categories may apply).

**Time Frame Change:**
  A Time Frame Change is defined as a substantive change to an outcome's time frame. This may include changes in timing, frequency, etc. This does *not* include removing an outcome completely and adding a different one in its place with a new time frame (i.e., the new outcome is unrelated to the original). This also does not include adding explicit information that was already inferrable; for example, you can always assume that there is a measurement at baseline. Be somewhat lenient with this category—only include substantial changes, and don't include small changes for the purpose of specificity or clarity.

**Addition:**
  Addition is defined as adding a new outcome to the list. This does not include splitting a single outcome into multiple outcomes.

**Removal:**
  Removal is defined as removing an outcome from the list. This does not include combining multiple outcomes into a single outcome.

**Other:**
  The Other category is for all changes that are not Time Frame Changes, Addition, or Removal. This includes simple changes to the language, spelling, capitalization, or formatting, as well as more contentful changes to the outcomes, such as adding additional or clarifying information, or editing an outcome's metric, analysis, or description.
